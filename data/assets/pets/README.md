# Generated pet assets

The four PNGs were generated with OpenAI's built-in image generation tool using `Plaid Chibi Pixel Pet.png` as the reference. Each prompt requested one transparent pixel-art portfolio asset preserving the reference character's identity, hair, facial hair, gray plaid shirt, dark trousers and black shoes, with no text or extra characters.

- `waving.png`: waving hello, full body, front-facing.
- `peeking.png`: peeking from behind a vertical edge, upper body visible.
- `hanging.png`: hanging by both hands from a horizontal ledge, full body dangling.
- `seated.png`: sitting comfortably with legs forward, full body.

Optimized transparent WebP copies in `public/pets` are uploaded to Neon for the page. The PNG originals remain available here.
